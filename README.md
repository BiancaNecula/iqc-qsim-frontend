# Quantum Simulator Frontend

## Overview

This project is a React-based frontend for the Quantum Simulator backend. It allows users to interact with the quantum simulator and visualize the simulation results.

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/BiancaNecula/iqc-qsim-frontend.git
    cd iqc-qsim-frontend
    ```

2. Install dependencies:

    ```bash
    npm install
    ```

3. Start the development server:

    ```bash
    npm start
    ```

4. Open your browser and visit `http://localhost:3000/` to view the React app.
